# Проверка сайта

Запусти из корня репозитория:

```bash
python3 .claude/skills/site-check/check_site.py
```

Скрипт проверяет:
- внутренние ссылки `href`/`src` ведут на существующие файлы;
- каждая страница из `sitemap.xml` существует, и каждая `index.html`
  (кроме служебных) есть в sitemap;
- `feed.xml` и `data/*.json` парсятся;
- у страниц с `hreflang` ссылка указывает на существующую страницу.

Дополнительно вручную:
- `git diff --stat` — изменены только нужные файлы;
- в изменённых страницах нет цен, имён покупателей и внутренних заметок;
- по-русски «на Филиппинах», «с Филиппин».

Ответ: «ОК» или список проблем с файлом и строкой и предложением исправления.
