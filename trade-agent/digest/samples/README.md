# Образцы выпуска: до и после переработки

Оба файла собраны одним скриптом `tools/sample_issue.py` на ОДНОМ И ТОМ ЖЕ
наборе материалов. Набор воспроизводит случаи, найденные при аудите
рабочей базы на Леново.

```bash
python tools/sample_issue.py --days 4 --out digest/samples/after.md
```

`before.md` получен тем же скриптом на коммите, предшествующем переработке
(прежние `alerts.py`, `radar/matcher.py`, `digest.py`). Сеть и модели не
использовались: оценки Scout заданы в наборе явно.

## Что изменилось

| Случай из набора | Прежний выпуск | Новый выпуск |
|---|---|---|
| Пошлины ЮАР на китайскую сталь | раздел «Срочно», оценка 5/5 | исключено: событие третьего рынка без связи с Филиппинами, РФ или маршрутом |
| Обзор рынка трески | попадал в регуляторные изменения | обычная карточка, срочности нет: предмета изменения правил в тексте нет |
| История бренда, «2023» | давала совпадения по общим словам | исключена, кодом товара год не считается |
| Бизнес-миссия российских компаний | отсекалась до модели («нет отраслевого ключевого слова») | короткая карточка о деловом контакте, без утверждений о готовой сделке |
| Одна новость в двух каналах | две отдельные карточки | одна карточка с двумя источниками |
| Филиппинский экспорт в РФ | «Кого ещё это касается»: рыба и напитки вперемешку | отдельный блок «Филиппины → РФ», роль компаний не подтверждена и так и написано |
| Анализ, завершённый с опозданием | не показывался: сигнал вне окна выпуска | карточка с исходной датой и пометкой о позднем подтверждении |
| Недоступный источник | не упоминался | «часть источников недоступна» в шапке |
| Счётчики шапки | считались до окончательного отбора | считаются по показанным карточкам |
| Внутренние баллы Scout | печатались в каждой карточке | вынесены в `/status` |
