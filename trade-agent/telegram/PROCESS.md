# Обработка pending.json → дайджест

Этот шаг требует суждения (оценка значимости, дедуп, формулировки) — его
выполняет Claude (вручную по запросу или по расписанию через Routine),
а не механический скрипт. Инструкция для того, кто это делает:

1. Прочитать `trade-agent/telegram/RUBRIC.md` — это правила фильтрации,
   оценки и формата. Следовать им дословно.
2. Прочитать `trade-agent/telegram/.raw/pending.json` (создаётся
   `fetch.py`). Если файла нет или он пуст — значит `fetch.py` ещё не
   запускали или новых сообщений не было; в latest.md зафиксировать
   «Значимых новых публикаций для проекта торгового агента не
   обнаружено» и не выдумывать контент.
3. Для каждого сообщения:
   - оценить по шкале 0–5 (см. RUBRIC.md);
   - отбросить (не пересказывать) всё с оценкой 0–2;
   - для оценки 3–5 — определить дубликаты между каналами (особенно
     Торгпредство ⇄ «Торгпред»), оставить одну запись, при необходимости
     указать другие места публикации;
   - заполнить все поля формата записи из RUBRIC.md.
4. Написать `trade-agent/telegram/latest.md` заново (полная перезапись)
   по структуре из RUBRIC.md.
5. Скопировать получившийся дайджест в
   `trade-agent/telegram/archive/YYYY-MM-DD.md` (дата запуска, UTC).
   Архивные файлы после создания не редактировать (кроме явных
   технических ошибок).
6. Обновить `trade-agent/telegram/state.json`: для каждого канала
   `last_message_id` = максимальный обработанный id из pending.json
   (если для канала не было новых сообщений — оставить как есть),
   `last_checked_utc` = время запуска.
7. Удалить/очистить `.raw/pending.json` (он не коммитится — см.
   .gitignore) — это внутренний буфер между шагами, а не часть
   постоянного архива.
8. Закоммитить `latest.md`, новый файл в `archive/`, `state.json` с
   понятным сообщением коммита. Не коммитить `.env`, `.raw/`.

Если давно не было ни одного значимого (3–5) сообщения несколько дней
подряд — это нормальный результат, а не повод расширять критерии ради
объёма (см. критерий успеха в исходном ТЗ: 0–5 полезных сигналов в день
— это хорошо).
