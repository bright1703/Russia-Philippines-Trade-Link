## Возможные действия

Мониторинг настроен (репозиторий, правила оценки, скрипт сбора), но ещё
не запускался: нет учётных данных Telegram API. Чтобы получить первый
дайджест, нужно:

1. Получить `api_id` и `api_hash` на https://my.telegram.org (раздел
   API development tools).
2. Локально, на своей машине, запустить
   `trade-agent/telegram/generate_session.py` — это одноразовый
   интерактивный вход в Telegram (номер телефона + код из приложения),
   он выведет `TELEGRAM_SESSION_STRING`. Этот шаг нельзя выполнить
   через Claude — вход требует кода, приходящего лично вам.
3. Заполнить `trade-agent/telegram/.env` по образцу `.env.example`
   (или добавить те же три значения как GitHub Actions secrets, если
   мониторинг будет запускаться по расписанию в CI).
4. Запустить `trade-agent/telegram/fetch.py` — первый запуск заберёт
   публикации за последние 7 дней по всем каналам из `RUBRIC.md`.
5. Попросить Claude (или запланированный Routine) обработать
   `trade-agent/telegram/.raw/pending.json` по правилам `RUBRIC.md` и
   перезаписать этот файл.

Подробности — в `trade-agent/telegram/SETUP.md`.
