# Правила мониторинга Telegram — торговый агент Приморского края на Филиппинах

Этот файл — рабочая спецификация для скрипта сбора (`fetch.py`) и для агента
(Claude), который на её основе оценивает сырые сообщения и пишет
`latest.md` / `archive/YYYY-MM-DD.md`. Менять этот файл можно только
осознанно — он единственный источник правил фильтрации и оценки.

## Географический приоритет

1. Филиппины (высший приоритет)
2. Приморский край, Дальний Восток России
3. Россия в целом
4. АСЕАН и Юго-Восточная Азия
5. Остальные страны — только если показывают полезный экспортный кейс,
   изменение регулирования РФ или товар, потенциально продвигаемый на
   Филиппины.

## Отрасли особого внимания

Мясо и мясная продукция, свинина, птица, продукты питания, мука и зерно,
овсяные хлопья, растительные масла, удобрения (включая органические),
торф и биоторф, картон и упаковка, промышленное оборудование,
автомобильная продукция, энергетика, логистика и морские перевозки,
сельхозоборудование, технологии с потенциальным спросом на Филиппинах.

Список не исчерпывающий: любая приморская компания или товар с очевидным
экспортным потенциалом на Филиппины — сохранять.

## Оценка значимости (0–5)

- **5** — требует внимания/действия сейчас: потенциальный покупатель,
  тендер, открытие рынка, изменение правил, возможность для действующей
  компании, запрос на товар, важная выставка, бизнес-миссия.
- **4** — высокая практическая ценность: можно использовать для поиска
  покупателей, подготовки предложения, работы с компанией проекта.
- **3** — полезная рыночная информация, стоит сохранить для анализа.
- **2** — общая отраслевая информация без очевидного действия.
- **1** — слабая связь с проектом.
- **0** — информационный шум.

**В дайджест попадают только 3, 4 и 5.** 0–2 не пересказывать вообще (даже
кратко) — просто не включать.

## Дедупликация

Одно и то же событие часто репостится между несколькими каналами
(особенно Торгпредство ⇄ «Торгпред»). Правила:

1. Определить первоисточник или наиболее информативную версию поста.
2. Сохранить **одну** запись.
3. При необходимости указать, где ещё был опубликован этот же материал
   (список каналов/ссылок).

## Формат записи (для каждой новости с оценкой 3–5)

- Дата публикации
- Источник (канал)
- Ссылка на оригинальный Telegram-пост
- Оценка (3–5)
- Категория
- Краткая суть (2–4 предложения)
- Почему это важно для торгового агента Приморского края
- Какие компании/товарные направления проекта это может затронуть
- Что можно сделать
- Нужна ли дополнительная проверка через официальные источники

## Достоверность

Публикация в Telegram сама по себе не делает факт достоверным. Для
регуляторных, статистических и коммерческих данных с оценкой 4–5 —
явно отмечать необходимость проверки первичного источника. Не
придумывать факты, не достраивать отсутствующую информацию.

## Структура `latest.md`

```
# Telegram Intelligence Digest

Дата проверки: ...
Проверено новых сообщений: N
Значимых сообщений: M

## Требует внимания
(только оценка 5)

## Высокая важность
(оценка 4)

## Полезно знать
(оценка 3)

## Возможные действия
(краткий список конкретных шагов для Андрея)
```

Если значимых новостей нет — писать прямо: «Значимых новых публикаций
для проекта торгового агента не обнаружено». Не заполнять файл общими
новостями ради объёма.

`latest.md` полностью перезаписывается при каждом запуске.
`archive/YYYY-MM-DD.md` — тот же дайджест, сохранённый на дату прогона;
после создания не редактируется (кроме исправления явной технической
ошибки).

## Обработка новых сообщений

`state.json` хранит последний обработанный `message_id` по каждому
каналу. Каждый запуск обрабатывает только сообщения новее сохранённого
id. Первый запуск — загрузка публикаций за последние 7 дней (см.
`fetch.py --first-run`), после — только новые сообщения.
