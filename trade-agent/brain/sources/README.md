| PhilGEPS | тендеры | государственные закупки | SPA-портал, разбор нестабилен |
| DA / BFAR / DOE / NFA | тендеры | закупки ведомств | вёрстка меняется |
| BAI | регулирование | допуски по животноводству | публикации нерегулярны |
| FPA | регулирование | регистрация удобрений | — |
| PSA | статистика | объёмы импорта | публикации с задержкой |
| Tariff Commission | тарифы | тарифные линии | — |
| Bureau of Customs | таможня | CMO/CAO | — |
| Telegram | сигналы | ранние сигналы отрасли | read-only, требует подтверждения |
