# Trade Agent Brain

Человекочитаемая база знаний торгового агента. Markdown правит человек,
система только читает.

| Каталог | Что внутри |
|---|---|
| `companies/` | профили компаний (YAML-заголовок + заметки) |
| `markets/` | обзоры рынков Филиппин по товарам |
| `regulations/` | требования, допуски, регуляторы |
| `sources/` | описание источников и что от них ждать |
| `playbooks/` | повторяемые процедуры работы |
| `opportunities/` | подтверждённые возможности, доведённые до работы |
| `contacts/` | контакты (импортёры, регуляторы, ассоциации) |

Правило проекта: **не заполнять выдуманными данными**. Пустое поле лучше
правдоподобной догадки. Всё непроверенное помечается как «требует проверки».

Профили компаний из `companies/*.md` автоматически подгружаются в базу при
каждом запуске `python -m trade_agent.process`.
