# Playbook: поиск филиппинского импортёра

1. Определить товарную группу и HS-код.
2. Собрать список компаний с действующей лицензией по этой группе
   (реестры ведомств, ассоциации, официальные списки).
3. Проверить, действует ли лицензия на текущую дату.
4. Подготовить короткое описание предложения на английском.
5. Первый контакт делает человек. Система писем не рассылает.
6. Результат зафиксировать в `brain/contacts/`.
