# Склейка одинаковых новостей (phnews)

## Что не так сейчас

В пяти выпусках `/philippine-trade-news/` (17.09–05.10.2026) 57 карточек,
из них 16 повторяют уже показанное событие:

| Событие | Карточек | Выпуски |
|---|---|---|
| Рекорд экспорта за август, $9.11B | 6 | 4, 5 |
| Соглашение PH-EU о свободной торговле | 5 | 2 |
| Инфляция за сентябрь (прогноз) | 2 | 4, 5 |
| Поэтапное повышение пошлин на свинину (DA) | 2 | 3 |
| Импорт риса 5.7 млн т в 2027 (USDA) | 2 | 3 |
| Кредит ADB $1.5B | 2 | 3 |
| Импорт мяса +8% за 8 месяцев (BAI) | 2 | 2 |
| ADB снизил прогноз роста | 2 | 2 |
| Импорт курицы в 2027 (USDA) | 2 | 1, 2 |

Сейчас повтор ловится только по совпадению ссылки или текста, а пять изданий
пишут об одном факте разными заголовками.

## Что делает `dedup.py`

1. **Слова и числа.** Сравнивает смысловые слова заголовка и начала выдержки
   с весом по редкости слова плюс общие числа ($9.11B, 5.7M MT). На этих
   57 карточках: 12 из 16 повторов убрано, ошибочных склеек нет.
2. **Модель (по желанию).** Получает список заголовков одним запросом и
   называет группы одного события. Нужна для случаев вроде PH-EU FTA.
   Может только добавить склейку и только между карточками с общими словами.
   Если ответ не разобран или запрос упал, остаётся результат шага 1.
   С моделью, отвечающей по ручной разметке, выходит 41 карточка из 57, как
   в ручной разметке. С настоящей моделью этот шаг ещё не проверялся.
3. **Повтор прошлых выпусков.** Группа, событие которой уже было в выпуске
   за последние 10 дней, не выходит снова. Разные стадии одного сюжета
   (пошлина на свинину: DA, потом Канада, потом импортёры) не считаются
   повтором.

Главной карточкой группы становится первоисточник (`*.gov.ph`, adb.org),
затем обычное издание, перепечатки msn.com последними. Остальные ссылки
группы можно показать строкой «Also reported by: …».

## Как подключить

Там, где phnews отбирает новости в выпуск, после фильтра по теме и до
перевода и записи в `ph_news_issues`:

```python
from trade_agent.phnews.dedup import deduplicate, drop_repeats, source_rank

groups = deduplicate(
    candidates,
    title=lambda n: n.title,
    extract=lambda n: n.summary,
    when=lambda n: n.published_at,
    rank=lambda n: (source_rank(n.url), -len(n.summary or "")),
    context=recent_published,        # карточки выпусков за ~3 недели
    ask=ask_model_or_None,           # та же модель, что пишет takeaway
)
groups, repeats = drop_repeats(groups, recent_published,
                               title=..., extract=..., when=...)
selected = [primary for primary, also in groups]
```

Названия полей (`title`, `summary`, `published_at`, `url`) заменить на
настоящие из phnews. `ask` — функция «текст промпта -> текст ответа».

Чтобы убрать повторы и из уже вышедших выпусков, ту же склейку можно
применить в `site_en.py` и `site.py` при сборке страницы по всем выпускам.

Проверка: `pytest tests/test_phnews_dedup.py`.
