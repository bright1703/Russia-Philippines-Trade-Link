# Tender Radar — Philippines

Второй, независимый модуль Trade Agent. Ежедневно проверяет официальные
филиппинские источники закупок, отбирает объявления, потенциально интересные
компаниям Приморского края, и формирует Markdown-дайджест.

Модуль не связан с `trade-agent/telegram/` и не меняет его логику.

## Что он делает

1. Обходит официальные порталы и страницы ведомств (см. `sources.yml`).
2. Приводит найденное к единой структуре (`normalize.py`).
3. Объединяет дубли одной закупки из разных источников.
4. При наличии PDF — скачивает во временную папку, вытягивает недостающие поля.
5. Сопоставляет с профилями направлений (`profiles.yml`, `match.py`).
6. Оценивает релевантность 0–5 и срочность дедлайна.
7. Пишет `latest.md` и архивную копию `archive/YYYY-MM-DD.md`.
8. Хранит историю в SQLite (`tenders.db`, в Git не попадает).

Фокус — **официальные публичные закупки**. Полнота по частным закупкам не
гарантируется, и система об этом честно пишет в шапке дайджеста.

## Установка

```bash
pip install -r trade-agent/tenders/requirements.txt
```

Python 3.10+. Playwright не требуется: в первой версии все источники
разбираются обычными HTTP-запросами.

## Запуск

```bash
cd trade-agent/tenders

python fetch_tenders.py                    # обычный ежедневный запуск
python fetch_tenders.py --dry-run          # ничего не пишет: ни архив, ни базу
python fetch_tenders.py --source philgeps  # только один источник (можно через запятую)
python fetch_tenders.py --days 7           # глубина периода проверки
```

Дополнительные флаги:

| Флаг | Назначение |
|---|---|
| `--store {sqlite,json}` | тип хранилища (по умолчанию sqlite) |
| `--no-pdf` | не скачивать и не разбирать PDF |
| `--keep-raw` | не удалять временные файлы из `.raw/` |
| `--fixtures DIR` | офлайн-режим на локальных HTML-файлах (`<source_id>.html`) |
| `-v, --verbose` | подробный лог в stderr |

Вывод в stdout — только сводка:

```
Sources checked: 5
New notices: 24
Updated notices: 7
Relevant notices: 8
Urgent notices: 2
Errors: 0
Digest: trade-agent/tenders/latest.md
```

Ошибки источников и подробности идут в stderr. Секреты, `.env`, cookies и
токены модуль не читает и не выводит.

## Офлайн-проверка без сети

```bash
python fetch_tenders.py --dry-run --fixtures tests/fixtures --no-pdf --days 30
```

## Тесты

```bash
cd trade-agent/tenders
python -m pytest tests -q
```

Тесты работают только на локальных фикстурах, сеть и секреты не нужны.

## Файлы

```
trade-agent/tenders/
  sources.yml        конфигурация источников (добавление = одна запись в YAML)
  profiles.yml       направления и ключевые слова компаний Приморья
  fetch_tenders.py   CLI-оркестратор
  normalize.py       нормализация, даты, статусы, канонический ID, дедупликация
  match.py           оценка релевантности 0–5 и проверка допуска
  pdf_extract.py     работа с PDF-приложениями
  render_digest.py   генерация latest.md и архива
  storage.py         SQLite/JSON-хранилище с историей изменений
  adapters/          адаптеры источников (base, generic_html, philgeps, fixture)
  tests/             тесты и локальные фикстуры
  latest.md          текущий дайджест
  archive/           ежедневные копии
  .raw/              временные файлы (в Git не попадают)
```

## Добавление источника

1. Добавить запись в `sources.yml` (id, name, url, adapter, priority, селекторы).
2. Если сайт нестандартный — создать класс в `adapters/`, унаследовать
   `BaseAdapter`, задать `adapter_id` и зарегистрировать в `adapters/__init__.py`.

Основная логика при этом не меняется.

## Ограничения, о которых нужно помнить

* Система **не подтверждает** право российской компании участвовать в закупке.
  В каждом объявлении печатается блок «Что проверить» и заметки о допуске.
* Facebook не используется как тендерный источник — только как канал ранних
  сигналов, и любая находка помечается как неподтверждённая.
* Не используются: cookies браузера, сессия Telegram, личные аккаунты,
  обход CAPTCHA и авторизации, агрессивный scraping.

Подробности ежедневного процесса — в `PROCESS.md`.
